## 重做
工作目錄要有：`fonts/jfliao_nohint.ttf`（jf-liao-proportional 用 fontTools 拿掉 hinting，不然 Pillow 會報 too many function definitions）、`fonts_cream.otf`（creamfont-3.4）、`hw/p00N.png`（`pdftoppm -r 330 -f N -l N -singlefile` 印刷檔 PDF）、v10 的 img/（q1、q2、q4、bag）。
1. `cd hw && python3 demo.py gift week reflect year`（v11 在 demo.py 加了 gift，扉頁座標用 1000 寬預覽值）
2. `python3 gif/wipe.py gift` → `gif/clips/hw_gift/`；03c 的 `gif/clips/f_open/` 從原商品頁外盒 v3 的 MP4 裁 `crop=1542:1928:0:0,fps=10,scale=1080:1350`
3. `python3 build_v11.py && python3 render.py out`（靜態區塊）
4. `python3 gif/render_gif.py` → `gif/secframes/s03c、s03d` → ffmpeg 出 GIF（600 寬、10fps、160 色）和 MP4（1080 寬、crf 20）
